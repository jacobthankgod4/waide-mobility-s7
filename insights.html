Editorial policy

Why we publish only a few notes

We publish notes when they can explain a specific part of our work. Each note is checked against project records, and we leave out claims we cannot support.

  • We write about work we can explain from project records.
  • We include authors, dates and sources only when we can verify them.
  • We publish client information only with permission.
  • We report pilot results only when they have been measured and can be shared.

Where a note refers to the Novare Lekki pilot, it describes method and scope. Operational outcomes from that pilot have not been published.
