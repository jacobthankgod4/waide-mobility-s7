Waide technology platform

The platform behind the mapping work.

A browser-based environment for publishing an indoor spatial model, routing visitors and giving operators a view of what is happening on the floor. It is in pilot use, not a finished public product.

Platform enquiry See the pilot

Stage statement: the platform is deployed in the Novare Lekki Mall pilot for the mapped scope. Features described as under development or planned are not available today. This page does not present a roadmap item as a delivered capability.

Pilot stage

Built for a venue, not for a demo.

The interface is deliberately plain: a level selector, a search box, a map, a text route and a step-free option. The value is in the data behind it, not in the visual effects.

Visitors reach it through a QR code and a browser. There is no app install. Operators use the same spatial model to see what was searched for and which routes were requested.

Architecture

Data outlives the interface.

The platform reads a structured spatial dataset: level geometry, spaces, facilities, network edges and a shelf index. The routing service computes paths over the relevant graph. The interface is replaceable.

That separation matters for clients. If the front end is rebuilt or the vendor changes, the dataset and schema remain usable. Export formats are standard, and the routing logic is documented.

  • Spatial data held in an open, documented schema.
  • Routing separated from presentation.
  • Role-based access for visitor and operator views.
  • No client data used to train third-party models.
  • Deployment configuration and backups documented at handover.

Platform questions

Common questions.

Can I buy the platform as a subscription?

Not at present. The platform is delivered as part of a mapping and deployment engagement. A subscription model is not offered while the product is at pilot stage.

Does it work without an internet connection?

Visitor access requires a connection to load the interface and route. Offline caching is not a released capability. Low-bandwidth behaviour is considered in the interface design.

Can it be deployed at our venue?

Potentially, after a data assessment. The venue needs a mappable layout and a team able to maintain the model. We will say if the scope does not fit the current stage of the product.

Is the pilot interface publicly accessible?

The public project record is on this website. The pilot environment itself is not published as a demo, and no client data is exposed here.
